# D WIKI

Открытая энциклопедия на Next.js App Router, React и TypeScript. Готова к размещению на Vercel.

## Возможности

- Лента статей, поиск, категории, сортировка, вид сеткой и списком.
- Markdown-редактор, предпросмотр, обложки, загрузка изображений и внешние ссылки.
- Автоматические синие ссылки: полные заглавия и отдельные слова из заглавий существующих статей. Учитывается регистр и граница слова; код и готовые ссылки не изменяются. При совпадении полное заглавие имеет приоритет, затем первая статья в ленте.
- Анонимное авторство: браузер хранит сессию, Supabase RLS проверяет права. Только автор может редактировать свою статью.
- Закладки, черновик новой статьи, адаптивный интерфейс.
- Без Supabase работает явно обозначенный локальный деморежим. **В этом режиме публикации не видны другим посетителям.**

## Локальный запуск

Требуется Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000.

## Общая база и изображения

1. Создайте проект [Supabase](https://supabase.com/).
2. Откройте SQL Editor и выполните `supabase/schema.sql` один раз в новом проекте.
3. В Authentication → Sign In / Providers включите **Anonymous Sign-ins**.
4. Скопируйте `.env.example` в `.env.local` и укажите URL проекта и **publishable / anon key**. Secret / service_role key не нужен и не должен попадать в клиент.
5. Перезапустите сервер. Демобаннер исчезнет, публикации будут сохраняться в общей базе.

Supabase хранит статьи в Postgres, изображения — в публичном bucket `article-images`. Файлы до 5 МБ: JPEG, PNG, WebP, GIF. Права редактирования проверяются на стороне базы, а не только интерфейсом. В деморежиме файлы до 1 МБ сохраняются в localStorage; для больших изображений используйте URL.

Шесть стартовых редакционных статей поставляются вместе с сайтом и не редактируются посетителями. Пользовательские статьи хранятся в базе. Для переноса локальных демостатей после подключения базы их нужно опубликовать заново.

## Vercel

1. В Vercel выберите Add New → Project → `AlexKraken444/D-WIKI`.
2. Framework Preset: **Next.js**; Root Directory: `./`.
3. Добавьте `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY` в Environment Variables.
4. Нажмите Deploy. Команда сборки — `npm run build` (стандартная).
5. После изменения переменных выполните Redeploy: переменные NEXT_PUBLIC встраиваются при сборке.

Без переменных Vercel тоже соберёт сайт, но он будет работать в локальном деморежиме. Для работы сайта не требуется записывать файлы в эфемерную файловую систему Vercel.

## Особенности

Анонимное авторство привязано к браузеру. Очистка данных сайта приводит к потере доступа к редактированию; восстановление аккаунта не предусмотрено. Приватный режим не сохраняет сессию после закрытия. Закладки и черновики доступны только в текущем браузере. Публикация общая, но интерфейс не подписывается на realtime: для новых статей другого автора обновите страницу.

Markdown не исполняет HTML; ссылки с опасными протоколами отбрасываются. Картинки и шрифты загружаются с внешних серверов (Unsplash / Google Fonts); интерфейс имеет системный шрифт на случай недоступности Google Fonts. Загруженные изображения публичны: не добавляйте приватные материалы.

Перед открытым массовым запуском настройте лимиты Supabase Auth и защиту от спама; модерация и восстановление авторства не входят в эту версию.

Фотографии стартовых статей: Unsplash. Тексты: редакционные демонстрационные материалы D WIKI.
